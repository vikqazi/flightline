# Granite Flyway

A waterfowl map for New Hampshire and Massachusetts, 2026–27 season.

**https://vikqazi.github.io/granite-flyway/**

Zone polygons are not sketched. They were built by routing along the actual
roads named in each state's written boundary description, and each state's
zones add up to its outline exactly.

Everything needed to read the map ships with the page, so it works with no
signal. Satellite and topo imagery, when switched on, do need a connection.

Sources and limitations are listed in the app under Regs → Sources, and in
LICENSE.
